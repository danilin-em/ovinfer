# VLMPipeline Support Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Wire `og.VLMPipeline` into `/v1/chat/completions` so chat requests carrying images run real vision inference, and VLM-export models serve text-only chats too.

**Architecture:** A model is detected as a VLM by the presence of `openvino_vision_embeddings_model.xml` on disk. VLM models are served through `og.VLMPipeline` for both text-only and image requests (kind `"vlm"`); plain LLM models keep `og.LLMPipeline` (kind `"llm"`) and reject image parts with a 400. Multi-turn history is rendered through the model's chat template with image parts replaced by `<ov_genai_image_N>` tags; all images load into a flat list of `ov.Tensor` passed to one `generate` call. Image loading happens eagerly (before any streaming headers) so bad images surface as 400. Streaming reuses the existing worker/queue/cancel machinery, parameterized by pipeline kind.

**Tech Stack:** Python 3.12, openvino-genai 2026.2.0, FastAPI, Pillow (new dep), numpy (transitive via openvino), `unittest` (run with `.venv/bin/python -m unittest`).

**Spec:** `docs/superpowers/specs/2026-06-10-vlm-design.md`

**Conventions from this codebase (read before starting):**
- All code/comments/docstrings in **English** (CLAUDE.md). Russian only in chat.
- `openvino_genai` and `openvino`/`PIL` are imported **lazily inside methods**, never at module top, so importing `ovinfer.backend` stays cheap and lib-free. Exception: `import base64`/`import binascii` are stdlib and go at the top.
- Tests never import `openvino_genai` for assertions; they stub `_pipeline`/`_generation_config` or the whole backend. (`import openvino_genai` does work in plain python here, but keep tests hermetic.)
- Run tests: `.venv/bin/python -m unittest discover -s tests -v` (no pytest installed).
- Real-model runs need the wrapper: `openvino-env .venv/bin/python ...` (global user rule).
- Domain errors carry no HTTP semantics; status mapping lives in `server.py:_ERROR_MAP`.

```python
_IMAGE_FETCH_TIMEOUT = 30.0


def _extract_image_url(part: dict[str, Any]) -> str:
    """Pull the URL out of an image content part (dict or bare-string form)."""
    raw = part.get("image_url")
    url = raw.get("url") if isinstance(raw, dict) else raw
    if not isinstance(url, str) or not url:
        raise InvalidImage("image content part is missing an image_url")
    return url


def _vlm_history(
    messages: list[dict[str, Any]],
) -> tuple[list[dict[str, str]], list[str]]:
    """Render messages for a VLM prompt.

    Text parts are kept; each image part becomes an <ov_genai_image_N> tag,
    N being a running zero-based index over the whole conversation in part
    order. Returns the chat-template-ready history plus the image URLs in tag
    order (one entry per tag). og substitutes the tags with image tokens at
    generate() time.
    """
    history: list[dict[str, str]] = []
    urls: list[str] = []
    for msg in messages:
        content = msg.get("content")
        if content is None or isinstance(content, str):
            history.append({"role": msg["role"], "content": content or ""})
            continue
        rendered: list[str] = []
        for part in content:
            ptype = part.get("type")
            if ptype == "text":
                rendered.append(part.get("text", ""))
            elif ptype in _IMAGE_PART_TYPES:
                rendered.append(f"<ov_genai_image_{len(urls)}>")
                urls.append(_extract_image_url(part))
        history.append({"role": msg["role"], "content": "".join(rendered)})
    return history, urls


def _fetch_image_bytes(url: str) -> bytes:
    """Return raw image bytes for a data: or http(s) URL; raise InvalidImage."""
    if url.startswith("data:"):
        header, sep, payload = url.partition(",")
        if not sep:
            raise InvalidImage("malformed data: URL (missing comma)")
        if ";base64" in header:
            try:
                return base64.b64decode(payload, validate=True)
            except (binascii.Error, ValueError) as exc:
                raise InvalidImage(f"invalid base64 in data: URL: {exc}") from exc
        import urllib.parse

        return urllib.parse.unquote_to_bytes(payload)
    if url.startswith(("http://", "https://")):
        import urllib.error
        import urllib.request

        try:
            with urllib.request.urlopen(url, timeout=_IMAGE_FETCH_TIMEOUT) as resp:
                return resp.read()
        except (urllib.error.URLError, OSError) as exc:
            raise InvalidImage(f"could not fetch image URL: {exc}") from exc
    raise InvalidImage(f"unsupported image URL scheme: {url[:32]!r}")
```

```python
def _load_image_tensor(url: str) -> Any:
    """Fetch and decode an image URL into an ov.Tensor (uint8 RGB, HWC)."""
    import io

    import numpy as np
    import openvino as ov
    from PIL import Image, UnidentifiedImageError

    raw = _fetch_image_bytes(url)
    try:
        pic = Image.open(io.BytesIO(raw)).convert("RGB")
    except (UnidentifiedImageError, OSError) as exc:
        raise InvalidImage(f"could not decode image: {exc}") from exc
    return ov.Tensor(np.array(pic))
```

```python
    def _chat_stream_gen(
        self,
        model_id: str,
        messages: list[dict[str, Any]],
        cfg: Any,
        kind: str,
        prepared: tuple[list[dict[str, str]], list[Any]] | None,
    ) -> Iterator[str]:
        import openvino_genai as og

        deltas: queue.Queue = queue.Queue()
        cancel = threading.Event()
        outcome: dict[str, Any] = {}

        def on_token(delta: str) -> Any:
            if cancel.is_set():
                return og.StreamingStatus.STOP
            deltas.put(delta)
            return og.StreamingStatus.RUNNING

        def worker() -> None:
            try:
                with self._pipeline(model_id, kind) as pipe:
                    result = self._generate(
                        pipe, kind, messages, prepared, cfg, on_token
                    )
                    outcome["result"] = self._chat_result(result, cfg)
            except BaseException as exc:  # propagated to the consuming thread
                outcome["error"] = exc
            finally:
                deltas.put(_QUEUE_END)

        thread = threading.Thread(
            target=worker, name=f"ovinfer-gen-{model_id}", daemon=True
        )
        thread.start()
        try:
            while True:
                item = deltas.get()
                if item is _QUEUE_END:
                    break
                yield item
        except GeneratorExit:
            # Client disconnected: ask og to stop at the next token, then wait
            # for the worker to release the device and the per-pipeline lock.
            cancel.set()
            thread.join(timeout=_CANCEL_JOIN_TIMEOUT)
            raise
        thread.join()
        if "error" in outcome:
            raise outcome["error"]
        return outcome["result"].finish_reason
```

## Notes on key decisions (for the implementer)

- **Why VLM serves text-only too:** VLM exports have no `openvino_model.xml`, so `og.LLMPipeline` cannot load them. `og.VLMPipeline` runs text-only prompts fine (empty image list). One pipeline per model in the cache; no separate kinds for the same model.
- **Why load images eagerly in `_resolve_chat_route`:** the streaming contract requires 404/400/501 to surface before headers. Image fetch/decode can fail (400), so it must run before the `StreamingResponse` is constructed — not inside the worker thread (which runs after headers are out).
- **Why `apply_chat_template = False` for VLM:** we render the full multi-turn history through the tokenizer's chat template ourselves (to support images in any turn and proper role formatting). og's default would re-wrap the prompt as a single turn. og still substitutes `<ov_genai_image_N>` tags with image tokens regardless of this flag. (LLM path is left exactly as-is — it is accepted/working.)
- **Tag indexing:** `<ov_genai_image_N>` N is a zero-based running index over all image parts in conversation order, matching the position of each tensor in the flat `images` list passed to `generate`.
